เว็บไซต์ 5ส เดือนพฤศจิกายน 2569: 5 ข้อ + เกมจับคู่ 8 คู่

สำคัญ: ห้ามรัน SQL หากยังไม่ได้สำรองคะแนนเดือนตุลาคม
1. สำรองตาราง submissions, questions, employees และ quiz_settings จาก Supabase ก่อน
2. ถ้ายังไม่เคยอัปเกรดระบบรายเดือน ให้รัน MONTHLY_UPGRADE.sql ก่อน (หากเคยรันแล้วข้าม)
3. ตรวจว่าเดือนปัจจุบันใน quiz_settings เป็น 2026-10 แล้วรัน NOVEMBER_SETUP.sql เพียงครั้งเดียว
4. รัน AFTER_NOVEMBER_SETUP.sql หลังข้อ 3 เพื่อให้เดือนต่อไปเก็บผลเกมย้อนหลังด้วย
5. Deploy โฟลเดอร์นี้บน Netlify โดยคง Environment Variables เดิม
6. เข้าหน้า Admin เปิดรับคำตอบและกำหนดวันเวลาปิดรับเดือนพฤศจิกายน
7. ทดสอบด้วยชื่อทดสอบที่สร้างใหม่ (อย่าใช้ชื่อพนักงานจริงในการทดสอบ)

หมายเหตุ: เกมมีการสุ่มการ์ด จับเวลา 3 นาที และเปิดหลังทำแบบทดสอบแล้ว; คะแนนเกมเก็บแยกจากคะแนนคำถาม
ข้อจำกัด: ตัวจับเวลาอยู่ในเบราว์เซอร์ ยังไม่ป้องกันการรีเฟรช/เปลี่ยนเครื่องเพื่อโกงอย่างสมบูรณ์ และ server ไม่สามารถพิสูจน์ว่าจับคู่ถูกจากข้อมูลที่ส่งมาเพียงอย่างเดียว; ใช้กับกิจกรรมสนุกสนาน ไม่เหมาะกับการแข่งขันที่มีรางวัลมูลค่าสูง
