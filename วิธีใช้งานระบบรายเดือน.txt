ระบบแบบทดสอบ 5ส รายเดือน WH FG (ถุง)

ก่อนอัปเดต: สำรองข้อมูลฐานข้อมูล Supabase และส่งออกผลเดือนตุลาคมเป็น CSV เก็บไว้ก่อน

1) เปิด Supabase ของเว็บไซต์เดิม > SQL Editor > New query
2) วางเนื้อหาจาก MONTHLY_UPGRADE.sql แล้วกด Run เพียงครั้งเดียว
   ห้ามรัน setup.sql ใหม่ และห้ามรันไฟล์ SQL ที่ลบข้อมูลเก่า
3) Deploy โครงการ ZIP นี้บน Netlify ด้วยวิธี Git repository / Netlify CLI ที่รองรับ Functions
   อย่าลากเฉพาะโฟลเดอร์ public เพราะจะไม่มี API Functions
4) เปิดเว็บ > สำหรับผู้ดูแลระบบ > ใส่รหัส Admin เดิม
5) ในส่วน จัดการแบบทดสอบรายเดือน กดดูประวัติย้อนหลัง (ครั้งแรกจะยังว่าง)
6) ตรวจสอบว่าเดือนปัจจุบันเป็น ตุลาคม 2569 และส่งออก CSV ผลเดิมเก็บสำรอง
7) เลือก 2026-11 แล้วกด สิ้นสุดเดือนเดิมและสร้างเดือนใหม่ พร้อมยืนยัน
   ระบบจะบันทึกสำเนาคำถามและผลตุลาคมใน quiz_history แล้วล้างเฉพาะผลชุดปัจจุบัน
   ปิดรับคำตอบอัตโนมัติ แต่คงรายชื่อพนักงาน รวมถึง เติ้ล
8) แก้ไขคำถามทั้ง 15 ข้อ และเฉลย แล้วกด บันทึกคำถาม 15 ข้อ
9) ตั้งวันเวลาปิดรับเดือนพฤศจิกายน แล้วติ๊ก เปิดรับคำตอบ กดบันทึก
10) เดือนถัดไปทำขั้นตอน 5-9 ซ้ำ ไม่ต้องแก้ SQL หรือ Deploy ใหม่

ข้อควรระวัง:
- การเปลี่ยนเดือนเป็นการดำเนินการจริง ย้อนกลับจากหน้าเว็บไม่ได้ จึงต้องสำรองก่อน
- หลังมีผู้ตอบในเดือนปัจจุบัน จะล็อกการแก้ไขคำถามเพื่อความยุติธรรม
- ผลเก่าจะอยู่ในตาราง quiz_history พร้อมคำถาม เฉลย และคำตอบรายคน
- ใช้หน้าแอดมินดูประวัติและดาวน์โหลด CSV ย้อนหลังได้
- ระบบจำกัด 1 ครั้งต่อพนักงานต่อเดือน ไม่ใช่ 1 ครั้งตลอดไป
- ต้องใช้ SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY และ ADMIN_PASSWORD เดิมใน Netlify
